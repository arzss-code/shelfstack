# Dokumentasi Proyek

> **Mulai dari sini:** `PROGRESS.md` (status terkini, wajib dibaca sebelum kerja) → `BACKLOG.md` (scope + acceptance criteria) → `ARCHITECTURE.md` (pola FSD-lite) → `MCP-SETUP.md` (setup tooling OpenCode).

Direktori ini digunakan untuk menyimpan seluruh dokumen teknis, API reference, atau panduan arsitektur yang berkaitan dengan proyek Product Management.

## Indeks — Rencana Portofolio Fullstack

- `PORTFOLIO-PLAN.md` — master plan 12 minggu, visi, arsitektur target, DoD global.
- `BACKLOG.md` — backlog MoSCoW + acceptance criteria (sumber kebenaran scope).
- `SPRINT-PLAN.md` — rincian Sprint 1–6: task file-by-file, checklist harian, demo script.
- `PHASE-0-FOUNDATION.md` … `PHASE-5-QUALITY-LAUNCH.md` — spec teknis per fase (SQL, API, UI, test).
- `ADR/` — keputusan arsitektur (Nuxt+Supabase, FSD-lite, cents+RPC).
- `PORTFOLIO-PACKAGING.md` — template README, CV, demo 2 menit.
- `MCP-SETUP.md` — setup MCP OpenCode (global vs per-project, secret, troubleshooting).
- `standup/` — laporan harian magang (morning plan + evening report per tanggal).

## Dokumen lama (tetap berlaku, sebagian status legacy)

- `PRD-ECOMMERCE.md`, `SOW-ECOMMERCE.md`, `DESIGN-ECOMMERCE.md` (era Nuxt 3 — baca sebagai konteks sejarah, bukan acuan implementasi), `ARCHITECTURE.md`, `DESIGN.md` (token oklch era pra-rebrand — desain aktif ada di `/DESIGN.md` root), `qa/`.
