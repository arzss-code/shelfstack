# Tutorial CRUD Supabase di Nuxt 3 & Standarisasi Talenavi

Dokumen ini adalah panduan komprehensif untuk memahami bagaimana fitur CRUD Produk dan Upload Gambar dengan Supabase diterapkan dalam proyek Nuxt 3 ini. Panduan ini dirancang dengan berpegang teguh pada prinsip _Clean Code_ dari Talenavi, _Vue Best Practices_ (Composition API), serta kewajiban kepatuhan terhadap `SOP-SUPABASE`.

## 1. Persiapan Database & Storage (Prasyarat)

Sesuai aturan _Supabase Postgres Best Practices_, pastikan tabel Anda mendefinisikan _Row Level Security (RLS)_ jika nanti data bersifat privat. Namun untuk tahap pengembangan ini, asumsikan kita memiliki tabel publik.

**Tabel `products`:**

```sql
create table public.products (
  id bigint generated by default as identity not null,
  name text not null,
  price numeric not null,
  description text null,
  link text null,
  image_url text null,
  created_at timestamp with time zone null default now(),
  constraint products_pkey primary key (id)
) tablespace pg_default;

-- Jika tabel sudah ada, jalankan ini di SQL Editor:
-- alter table public.products add column description text null;
-- alter table public.products add column link text null;
```

**Bucket Storage:**
Buat _bucket_ bernama `product-images` dan atur agar bersifat _Public_ (sehingga gambar dapat diakses langsung menggunakan URL).

## 2. Kredensial & Cegah Crash SSR

Proyek Nuxt membutuhkan URL dan Key untuk berinteraksi dengan Supabase. Ini diatur secara aman menggunakan file `.env`:

```env
NUXT_PUBLIC_SUPABASE_URL=https://<project_id>.supabase.co
NUXT_PUBLIC_SUPABASE_KEY=<anon_key>
```

> [!WARNING]
> **Penting (Mencegah SSR Crash):** Modul `@nuxtjs/supabase` **wajib** mendeteksi variabel _environment_ ini. Jika Anda mencoba menjalankan Nuxt (khususnya Nuxt 4) tanpa file `.env`, _plugin_ Supabase akan gagal dimuat (throw warning) dan hal ini dapat memutus rantai inisialisasi _plugin_ lain seperti `@pinia/nuxt`. Hal ini akan menyebabkan _crash_ fatal `Cannot read properties of undefined (reading 'state')` di _hook_ `app:rendered`. Selalu pastikan kredensial Anda terisi (sekalipun _dummy_ saat tahap pengembangan UI).

## 3. State Management dengan Pinia

Sesuai _Vue Best Practices_, kita harus memastikan _state_ tetap dapat diprediksi dengan memisahkan logika orkestrasi di dalam `stores` (misal: `app/stores/product.ts`). Di Nuxt 3 dengan `@nuxtjs/supabase`, kita menggunakan composable `useSupabaseClient()` untuk memanggil API.

### A. Fetch Data (Read)

```typescript
const fetchProducts = async () => {
  const { data, error } = await supabase
    .from("products")
    .select("id, name, price, description, link, image_url") // Praktik terbaik: jangan gunakan select('*')
    .order("created_at", { ascending: false });

  if (error) throw error;
  products.value = data || [];
};
```

### B. Upload Image (SOP Kepatuhan Storage)

Mengacu pada `SOP-SUPABASE` Bab 2, **dilarang keras mengunggah foto mentah berukuran besar langsung ke Storage**. Kita wajib membatasi unggahan awal maksimal 5 MB, hanya menerima format (JPEG, PNG, WebP), dan melakukan **kompresi sisi klien (Browser)** menggunakan HTML5 Canvas API agar ukuran yang terkirim ke server idealnya di bawah 1 MB (WebP).

Proses ini ditangani secara khusus di komponen `app/components/ProductForm.vue`:

```typescript
const compressImage = (file: File): Promise<File> => {
  return new Promise((resolve, reject) => {
    // 1. Baca file
    const reader = new FileReader();
    reader.readAsDataURL(file);
    reader.onload = (event) => {
      const img = new Image();
      img.src = event.target?.result as string;
      img.onload = () => {
        // 2. Siapkan Canvas & Batasi Lebar Maksimal (1200px)
        const canvas = document.createElement("canvas");
        const MAX_WIDTH = 1200;
        let { width, height } = img;

        if (width > MAX_WIDTH) {
          height = Math.round((height * MAX_WIDTH) / width);
          width = MAX_WIDTH;
        }
        canvas.width = width;
        canvas.height = height;

        const ctx = canvas.getContext("2d");
        ctx?.drawImage(img, 0, 0, width, height);

        // 3. Ekspor ke WebP (Quality 70%)
        canvas.toBlob(
          (blob) => {
            if (blob) {
              resolve(
                new File([blob], file.name.replace(/\.[^/.]+$/, "") + ".webp", {
                  type: "image/webp",
                }),
              );
            } else reject("Gagal kompresi");
          },
          "image/webp",
          0.7,
        );
      };
    };
  });
};
```

Setelah gambar dikecilkan secara instan di browser pengguna, barulah fungsi di Pinia `uploadImage()` mengirimkannya:

```typescript
const uploadImage = async (file: File) => {
  const fileName = `${Math.random()}.webp`; // Selalu .webp dari hasil kompresi
  const { data, error } = await supabase.storage
    .from("product-images")
    .upload(fileName, file);

  if (error) throw error;
  return supabase.storage.from("product-images").getPublicUrl(fileName).data
    .publicUrl;
};
```

### C. Update & Delete Data

Prinsipnya mirip dengan Create.

- **Update**: Gunakan `.update(payload).eq('id', targetId)`
- **Delete**: Gunakan `.delete().eq('id', targetId)`

> [!TIP]
> Jika Anda menghapus produk, Anda secara arsitektural idealnya juga memicu penghapusan _file image_ dari storage untuk menghemat ruang.

## 4. UI dan UX (PrimeVue)

### A. Dialog & Form (`ProductForm.vue`)

Kita memecah form ke komponen terpisah agar `index.vue` tetap bersih. Form dibungkus menggunakan komponen `<Dialog>` dari PrimeVue agar pengguna tidak mengalami perpindahan halaman (_context switch_). Validasi file ditangani di komponen ini dan mencegah eksekusi `.emit('save')` jika file melanggar SOP.

### B. Global Toast Notifications

Untuk memberitahu pengguna mengenai hasil dari validasi file (sukses dikompresi, ditolak karena format, atau ditolak karena ukuran mentah > 5MB), kita mengaktifkan `<Toast />` di _root_ `app/app.vue` dan memanggil `useToast()` di setiap komponen yang membutuhkan.

```vue
<!-- app/app.vue -->
<template>
  <div>
    <Toast />
    <!-- Merender pop-up notifikasi secara global -->
    <NuxtLayout>
      <NuxtPage />
    </NuxtLayout>
  </div>
</template>
```

Dengan mengikuti standar tutorial terbaru ini, aplikasi Anda akan:

1. **Sangat Hemat Biaya (Egress)** karena implementasi Native Canvas Compression.
2. **User Friendly** dengan hadirnya Toast Notifikasi PrimeVue.
3. **Lebih Aman & Stabil** (Bebas dari fatal SSR Pinia error berkat setup kredensial yang tepat).
